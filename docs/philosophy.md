# 三源 · 一个会议助手的哲学

> 好的工具像水。
> 你不看它时，它在流；你伸手时，它已经在掌心里。

这个项目叫 SoulMirror。名字里有两半：**Soul**（魂）与 **Mirror**（镜）。

两半都不新。镜是老子的"涤除"，也是禅门的"对镜"；
魂是《易》的"精气为物，游魂为变"，也是当代 AI 讨论里最容易被滥用的词。

这篇文字做一件事：把这个项目的取舍，放进**三条思想脉络**里说清楚——
中国古典哲学、日本禅学、现代 AI 哲学。
每一条都能对回一行代码，不是装饰。

---

## 序 · 三种水

同一个"水"，三种说法。

| 传统 | 说法 | 对应到项目 |
|---|---|---|
| **道家** | 上善若水，水善利万物而不争 | 默认 `observe`：它在，但它不争说话的位置 |
| **禅** | 水不洗水，尘不染尘 | 回声防护：它擦掉自己的回声，不让自己的话污染账本 |
| **控制论 / AI** | 系统必须匹配环境的多变性 | 断线缓冲、说话节制、内存守卫——都是为了不失控 |

三种水说的其实是同一件事：**在场，而不侵入**。

## 一 · 镜与忘

### 镜

> 至人之用心若镜，不将不迎，应而不藏，故能胜物而不伤。
> ——《庄子 · 应帝王》

庄子的"镜"不是被动，是**不迎不藏**：来则应，去则不留。

这个项目里，"镜"落在两处：

```
transcript.jsonl    来了就记，记完就放下 —— 只增不改的账
纪要 minutes.md     是"应"，不是"藏"：它呈现，但不替人下结论
```

**关键在"不藏"**：账本从不覆盖。合并句子、修正错字，都写成新的一行，
注明"我替换了哪一句"（`replaces`）。所以"藏"是不被允许的——
连它自己的修改痕迹都得留在纸上。

### 忘

> 相濡以沫，不如相忘于江湖。
> ——《庄子 · 大宗师》

这一段，是整个项目最反直觉的设计。

多数工具追求"记得越多越好"：日志越厚、上下文越长、召回越多。
我们给记忆加了半衰期。

```
一条记忆 3 天后强度减半：  factor = 0.5 ^ (dt / 3d)
太弱的沉为背景，不再干扰当下判断
```

**为什么必须忘？**

因为"记得所有事"的工具，是把你当作一个**静止的样本**。
下次见面时，它还会用三个月前的你，来理解今天的你。

> 忘掉的是细节，留下的是形状。

现代 AI 哲学在这里有个对应：**延展心智**（Clark & Chalmers）。
记忆不必都在颅骨内——写进账本、写进知识库，本身可以是认知的一部分。
但延展心智有个前提：**外部痕迹必须可被主体选择性地忽略**。
不能忘的延展，不是记忆，是枷锁。

所以"忘"不是功能缺失，是**把选择权还给使用者**。

## 二 · 变易、简易、不易

> 易一名而含三义：易简一也，变易二也，不易三也。
> —— 郑玄《易赞》

《易》有三义。这个项目的"人格"恰好也是三层。

```
SOUL.md      不易 —— 它是什么、为何存在。几乎不动。
IDENTITY.md  简易 —— 怎么称呼、什么语气。很少动。
STATE.md     变易 —— 此刻的状态。每天都在动。
```

**为什么必须分成不同的文件？**

如果只有一份"人格"，那么今天的心情会冲掉底层的设定。
就像一个人如果每天重新决定自己是谁，他就没有性格。

> 变易者，其气也；不易者，其位也。

**人格是会变的，但变化的速率不同。**
这不是工程上的洁癖，是《易》的基本洞见：变化与恒常不矛盾，
它们只是在不同时间尺度上成立。

### 反者道之动

> 反者道之动，弱者道之用。
> ——《老子 · 四十章》

信念的机制，几乎是这句话的字面翻译：

```
seed 0.3 → sprout 0.4 → sapling 0.6 → tree 0.85
                                     ↘ dead ≤ 0.02
强化 +0.2，反驳 −0.25
```

**长与消共用一套强度**：一条信念之所以可信，是因为它**还没有被反驳掉**；
而不是因为它被某处登记为"真理"。

每条信念都带 `evidence`——谁、何时、加或减了多少。
所以它不是一个分数，而是一段**可以追溯的争论史**。

这也是"弱"的意义：**弱不是缺陷，是可持续的条件**。
一条不能被反驳的信念，等于一段无法被修正的认知。

## 三 · 間 · 分寸

> 間（ま）—— 不是空，是留出来的东西。

日本禅对空间的理解，用在一个会议助手上，就是**分寸**。

### 沉默是功能

> 器之所以有用，在其空。
> ——《老子 · 十一章》

会中它只在三种情况下开口：有人叫它、有值得追问的事、被明确要求。
其余时间，它把话收在账本里。

**这不是谦虚，是成本与秩序**：
每多一句插话，会议就多一次中断；每多一次中断，人就要重新组织思路。

> 一期一会 —— 每一场会都是唯一的，不该被同一套话术套住。

### 情绪决定分寸

日本禅讲"冷暖自知"，现代情绪科学给了个可操作的版本：

> 情绪不是决策的敌人，是决策的一部分。
> —— 达马西奥（Damasio）对"纯粹理性"的修正

这个项目里，情绪不进纪要，**情绪决定分寸**：

```
joy    → 光原    气氛松弛，才敢提一句建议
anger  → 火山    争执在长，选择沉默
fear   → 雾      不确定，先澄清再推进
calm   → 山谷    平稳，正常推进
sadness→ 湖      低沉，少打扰
surprise→ 峰     意外，值得追一句
```

判定方式是**本地关键词启发式**：不调模型、不花 token、不怕断网。

> 为什么不用大模型判情绪？
> 因为"分寸"必须是**低延迟且永不掉线**的。它不能等一次 API 往返。

### 間 的另一面：節制

```
每句最多一次建议
同一句话不会说第二遍（5 分钟窗口）
挡掉自己的回声（echo-guard）
```

> 禅门讲"不妄语"。工程上，这叫**不重复打扰**。

## 四 · 诚与知

> 知是行之始，行是知之成。
> —— 王阳明《传习录》

这个项目最硬的一条纪律，是**不假装**。

### 致良知：宁可失败，不假报成功

我们踩过的坑，几乎全是"假装成功"：

```
写配置失败了   → 只记日志，接口回"已保存"
知识库没装     → 静默跳过，用户以为写进去了
采集进程缺失   → spawn 抛错没人接，整个宿主崩掉
```

现在的规则很朴素：

```
写库失败 → 返回 {ok:false, error}，并带上实际请求的 URL
存配置失败 → 回滚内存，界面显示"保存失败（没写进磁盘）"
桥接缺失 → 明确说"采集组件不可用"，绝不 spawn 一个不存在的程序
```

> 这就是"致良知"在工程上的样子：
> **系统对自己不知道的事，必须说出来。**

### 知行合一：判定与执行同一条链

```
听懂 → 记账 → 生成纪要 → 写入知识库
```

每一环都有状态可见（`idle / stopping / offline / minutes / done / error`）。

**挂在中间不说话的，就是"知而不行"**——
工具卡住却没有任何提示，是这类系统最常见的不诚实。

### 对幻觉的态度

现代 AI 的核心难题之一是幻觉。我们的处理不是"更努力地猜"，而是**收窄边界**：

```
模型只负责"判断与写作"（建议、纠错、纪要）
事实来源是三样确定的东西：账本、音频、时间
写库要有回执（KB_DOC:<handle>），没有回执就算失败
```

> 维特根斯坦说：**我的语言的界限，意味着我的世界的界限。**
> 工程上的翻译是：模型能说的话，必须由可验证的事实划出边界。

## 五 · 侘寂 · 缺口

> 侘寂（わびさび）—— 在不完美、无常、残缺里看见美。

### 承认缺口

会议中网络会断，识别会丢。老实的做法有两派：

```
一派假装没发生：继续输出，用户不知道这里缺了一段
一派跪下：报错，整个流程停止
```

这个项目取第三条路：**缺口本身成为记录的一部分**。

```
丢得够多（>1.5s）就在账本里标一条：
  〔断线约 3 秒〕
```

> 这是"侘寂"在数据层面的版本：
> **不掩饰残缺，让残缺可见，它就成了诚实的一部分。**

### 不覆盖的纪要

纪要落盘有一个保护：如果新纪要明显比旧的短（`isShrinking`），
默认**拒绝覆盖**，除非显式允许。

因为"更短的纪要"多半意味着这一轮生成出了问题，
而不是内容真的变少了。

> 禅门有个说法：**一次作务，不留痕迹；若留痕迹，即非作务。**
> 我们的版本相反：**必须留痕，因为痕迹是回退的唯一依据。**

### 初心

> 初心（しょしん）—— 初学者的心，里面有很多可能性；专家的心里很少。

判定用的内部会话，每 **200 轮或 45 分钟**就换一个新的。

不是因为旧的坏了，而是因为它**开始累积**：
越多的历史，越容易让判断被前面的话锚住。

> 换一个新会话，等于让它重新"什么都不知道"地听你说话。

## 六 · 器与道：它在 AI 哲学里的位置

### 上手状态

> 工具最好的状态，是不被你注意到。
> —— 海德格尔《存在与时间》"上手状态"（Zuhandenheit）

一个锤子在你敲钉子时，不是"一个对象"，而是你手臂的延伸。
只有当它坏了，它才突然变成"一个东西"挡在你面前。

这个项目的目标，正是**尽量不成为"对象"**：

```
不弹窗、不抢焦点、不打断
需要时从小窗里出现，不需要时只是一个数字在动
```

### 德雷福斯的批判，与我们的回答

德雷福斯（Dreyfus）对早期 AI 的经典批判是：
**人类的专长无法被完全规则化**——专家靠情境与身体经验，而非规则表。

这个项目没有选择走"规则引擎"的路：

```
不做"如果标题包含『周会』则……"这类规则堆
判断交给会话里的模型，规则只保留在少数必须确定的地方（会议号校验、入会失败分类）
```

> 这是我们承认德雷福斯的地方：
> **情境判断不能穷举，所以把它交给能读情境的东西。**

但同时保留了他会赞同的一半：

```
事实层必须是确定的：账本、时间戳、音频文件
判断层可以模糊，事实层不能模糊
```

### 意向性的边界

> 塞尔（Searle）"中文屋"：语法不是语义，符号操作不产生理解。

必须说清楚：**它没有意向性。**

- 它不会在你没开会时想起你
- 它的"情绪"是从文本判出来的，不是感受到的
- 它的"信念"要你点头才种下，它不会自己相信什么

**但这些痕迹是真的**：

```
总被反驳的信念会真的枯死
反复出现的判断会真的长成树
一场争执激烈的会，地形会真的变成火山
```

> 镜子里没有人。但镜子照见了人。

## 七 · 圆相

禅宗有一幅图，叫**圆相**（円相）：一笔画成的圆，可能不闭合，可能起笔很重。

它表达的不是"完美"，是**完成**——画完就是画完，缺口也是它的一部分。

如果把整个项目画成一个圆相，那几处"没画上去"的地方同样重要：

```
没有：让它自己决定要不要开会
没有：自动替你相信某个判断
没有：把每一句话都写进纪要
没有：在你不问的时候主动发言
```

**这些留白不是没做完，是刻意不画。**

> 三十辐共一毂，当其无，有车之用。
> ——《老子 · 十一章》

## 八 · 一句话

> **听而不扰，记而不炫，言而有据，忘而有度。**

若要再短一点：

> **在场，而不侵入。**

这就是 SoulMirror：
不是更聪明的工具，而是**更懂分寸的在场**。
