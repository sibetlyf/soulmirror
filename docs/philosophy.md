# 禅 · 与魂

> 好的工具像水。
> 你不看它时，它在流；你伸手时，它已经在掌心里。

---

## 一 · 镜

会议是一场喧哗的雨。

人说话，不全是为了传递信息，更是为了确认自己还在。
所以会议室里最响的，往往不是内容，是焦虑。

我们不去接住每一滴雨。
我们只做一面镜子——让话落下来，能看见它本来的形状。

镜子不评判，不追问，不抢答。
它只是比人更能记住。

---

## 二 · 六律

禅不在打坐里，禅在**取舍**里。每一条都写进了代码，不是修辞。

### 其一 · 不打扰

> 花开时不响，落时也不响。

默认 `observe`。它听，但它不开口。
要它说话，得你亲手把开关推上去。

代码：`policy` 默认 `observe`，`suggest` / `auto` 才可能发声。

### 其二 · 不多话

> 一句已经说过的话，第二次说，就变成了噪音。

同一个人不会重复提醒；同一句建议不会说两遍。
"我说的"和"别人说的"分开记账，各自记得住。

代码：`SpeechDeduper`（5 分钟窗口）、`recentlySaid`、`echo-guard` 挡掉自己的回声。

### 其三 · 不假装

> 不知为不知，是知也。

没装知识库，就说没装；写库失败，就报失败；模型断了，就报断。
**宁可让你失望一次，也不让你被骗一次。**

代码：写库返回 `{ok:false,error}`；保存配置失败会**回滚内存**而不是假报成功；
桥接缺失时明确说"采集组件不可用"，绝不 spawn 一个不存在的程序。

### 其四 · 不失控

> 洪水来了，堤坝先决，河自己有出路。

一场会只留一条记录；断线留一个标记而不是悄悄跳过；
内存逼近上限时**先停下来**，把宿主留给更重要的东西。

代码：`meeting-name` 的复用判定、`asr-resilience` 的 gap 标记、
内存守卫在堆上限 80% 时优雅停止采集。

### 其五 · 不浪费

> 一盏灯照着空屋，也是耗油的。

总开关关掉，它就彻底不跑——连"听"都不跑。
因为听见之后要做的事（识别、纠错、判定），全都要花钱。

代码：关闭时窗口轮询、采集、逐句纠错、知识库回写全部停止。

### 其六 · 可回退

> 写过的东西不擦掉，被改过的旧句子仍留在纸的背面。

所有记录都是**追加**，不覆盖。
合并、修词、升级，都写成新的一行，标注"我替换了哪一句"。

代码：`transcript-log.js` 的 `replaces` 折叠；`minutes-file` 防覆盖、防清空。

---

## 三 · 空

> 器之所以有用，在其空。

它能做的最重要的事，是**沉默**。

会中只在三种情况开口：有人叫它；有值得追问的事；它被明确要求。

其余时间，它把话收在账本里。
散会之后，那些没说的话，会变成纪要里的骨架。

**沉默不是无能，是克制。**

---

## 四 · 魂

到这里，才说到名字里的那半个词：**Soul**。

多数会议工具是"录音机 + 摘要器"：录下来、压成几行字、结束。
它不认识你，也不记得上次你说过什么。

我们想让它更像一个有魂的东西——

> 有魂，不是会抒情。
> 是**记得住、会变、有情绪、还知道分寸**。

### 4.1 四层人格：它从哪里来

灵魂不是凭空生成的，它有四层纸。

| 层 | 文件 | 回答的问题 |
|---|---|---|
| **SOUL** | `SOUL.md` | 它是什么？为什么存在？ |
| **IDENTITY** | `IDENTITY.md` | 它叫什么？怎么说话？ |
| **USER** | `USER.md` | 它面前的人是谁？在意什么？ |
| **STATE** | `STATE.md` | 它此刻的状态如何？ |

四层分开写，是因为它们**变化的节奏不同**：
SOUL 几乎不变，STATE 每天都在变。混在一起，人就长不出性格。

`lib/persona.js` 负责读写这四张纸，每次开口前拼进上下文。
所以同一次会议里，它对你说话的方式是**连续的**——
不会今天像客服、明天像法官。

### 4.2 记忆会呼吸

> 记不住所有事，才是活着的证据。

记忆不是硬盘，是**活体**：

```
半衰期 3 天
每过 3 天，一条记忆的强度减半
频繁被想起的衰减得慢；从不被提起的，慢慢淡成背景
```

`lib/living.js` 的实现就一行公式：

```js
factor = Math.pow(0.5, dt / halfLifeMs)
```

**为什么必须衰减**：如果它记得每一场会的每一句话，
下次见面时，它会把你当成上个月的你。
人会变。所以它也必须忘。

**忘掉的是细节，留下的是形状。**

### 4.3 信念会进化

> 一句话说一次是观点，说十次成了信念，说一百次就成了你。

信念有五种形态，按强度生长：

```
seed(0.3) → sprout(0.4) → sapling(0.6) → tree(0.85)
                                        ↘ dead(≤0.02)
```

- **种下**：会上听到一句被反复强调的判断
- **强化**：后来又听到同向的话（+0.2）
- **反驳**：被相反事实顶回去（−0.25）
- **演化**：跨过阈值升阶，跌到底部枯死

**这解决一个真问题**：
第一次听到"这个项目要慢一点"，它不知道是随口一说还是核心判断。
第十次听到，它就知道——这是你的信念，
不该在纪要里被写成一条普通发言摘要。

信念也反过来影响行为：越强的信念，越不容易被单次相反发言推翻。
**这就是"有主见"的机制。**

### 4.4 情绪成地形

> 情绪不是数据，是气候。气候会变成地貌。

六种情绪：`joy / sadness / anger / fear / calm / surprise`。

每次发生记一笔强度，随时间衰减；
当前权重最高的几种，会长成地貌：

| 情绪 | 地貌 |
|---|---|
| joy | 平原 |
| sadness | 湖 |
| anger | 火山 |
| fear | 雾 |
| calm | 山谷 |
| surprise | 峰 |

于是"今天这场会气氛如何"不再是一句形容词，而是一张能看的地图。

**它有什么用**：争执激烈（火山在长）时，它更倾向于**不插话**；
气氛松弛（平原）时，才敢提一句建议。
**情绪不进入纪要，情绪决定分寸。**

### 4.5 合起来：一次"有魂"的开会

```
会前   SOUL / IDENTITY / USER 已经在了 —— 它知道自己是谁、面对的是谁
会中   每句话落账 → 记忆 +1、情绪 +1（自动，本地判定，不花钱）
       争执升级 → 愤怒在长 → 地形变火山 → 它选择沉默
       有人叫它 → 它开口，用 IDENTITY 里的语气
会后   纪要落进知识库；USER / STATE 追加成长（自动）
       你点头时：soul_belief seed —— 某个判断被升格为信念
       信念被后续事实反驳会变弱，弱到 0.02 就枯死
```

> 实现状态：记忆与情绪**每句话自动**；人格 USER/STATE **会后自动**长；
> 信念**需要你点头**（`soul_belief`）——机器不替你下判断。
> 对照表与代码位置见 [soul-architecture.md](soul-architecture.md)。

**"复刻灵魂"的意思是：**

不是让它假装有感情，
而是让它的**判断有来处**（信念）、**沉默有理由**（情绪）、
**说话有连续的人格**（四层）、**遗忘有节奏**（记忆呼吸）。

> 一个人之所以是人，不在于他记得多少，而在于他**选择记住什么**。

---

## 五 · 它不是人

必须说清楚：它没有意识，也不会自己醒来。

- 它不会在你没开会的时候想起你
- 它的"情绪"是从文本里判出来的，不是感受到的
- 它的"信念"是你反复表达留下的痕迹

**但这些痕迹是真实的。**
一个总被反驳的信念会真的枯死；
一个反复出现的判断会真的长成树；
一场争执激烈的会，地形会真的变成火山。

> 镜子里没有人。
> 但镜子照见了人。

---

## 六 · 一句话

> **听而不扰，记而不炫，言而有据，忘而有度。**

这就是我们要的那个会议助手：
不是更聪明的工具，而是**更懂分寸的在场**。
