# SoulMirror：一个名字里的设计

> 名字就是设计。
> **Soul** 与 **Mirror**——一半是照见，一半是心动。

这篇文字不引经据典，只做一件事：
把项目里每一个功能，落回名字里的那两半，看它**为什么必须是这样**。

---

## 一 · 名字

```
Soul       魂
Mirror     镜
```

**镜照人，魂生念。**

一面镜子不该有主张——它照出什么就是什么。
一个魂不该没有主张——否则它只是回声。

这两件事同时做，才有麻烦：
镜子太像人，就会**编**；魂太像镜，就会**空**。

项目里几乎所有的取舍，都是在这两个方向的**拉扯**中定下来的。

---

## 二 · 镜的一侧

> 镜不自照，故能照物。

### 2.1 采集：映

环回采集整场会议的声音，不录音像、不采集屏幕。
只看"声音"这一面，因为会议**真正发生的部分在声音里**。

```
映，不是搜。
它不主动去房间里找东西，只是让声音落到它面前。
```

### 2.2 转写：影随形

实时转写不是"记录"，是**影子**。
影子会随身体动，也会短暂模糊——所以转写允许"中间结果"存在，
随后由更完整的句子覆盖。

```
影随形，不先于形。
不许它抢在对方说完之前下结论。
```

代码：同一句的"半句"和"整句"只留一行（`replaces` 标记）。

### 2.3 账本：只增不改

镜子里照到的东西，**不允许事后修改**。
合并、纠字，都不是擦掉重写，而是**再照一次**，注明"我替换了哪一句"。

```
改，也要留下改的痕迹。
否则账本就成了另一个人的叙述。
```

代码：`transcript.jsonl` 全部是追加；回放时按 `replaces` 折叠。

### 2.4 去重与回声：镜不照镜

如果镜子对着另一面镜子，会照出无限深。
所以：

```
同一句话短时间重复到达 → 只收一次
模型自己的话被听回麦克风 → 挡掉（echo-guard）
```

**镜不照镜，是防止自恋，也是防止无限循环。**

### 2.5 缺口：缺而不掩

网络会断，识别会丢。三种做法里我们选第三种：

```
装作没发生      → 用户在不知情的地方被骗
整个停下报错    → 一场会因为没有一段就废掉
留下缺口本身    → 〔断线约 3 秒〕
```

> 镜面有裂，就让裂纹留在镜面里。
> 掩饰裂纹，才是真的坏了。

代码：`shouldMarkGap`（>1.5 秒才标）、`gapText`；纪要还有防覆盖（`isShrinking`）。

### 2.6 回放：水落石出

账本是"只增不改"的，所以读的时候要**还原**：
把被替换的句子折叠掉，只剩最终的样子。

```
不是为了好看，是为了让"当时说的"和"最后定的"分得开。
```

### 2.7 演练：镜中花

演示模式里，会放一段样例音频，走完整条链路，但**不连接真实会议**。
它是镜子里的花——看得见，摸不到。

> 为什么要它？
> 因为"证明自己能用"这件事，不该先让你开一场真会。

### 2.8 恢复：续影

进程被强杀，账本还在；纪要没生成。
重启后会**主动**列出来："这 N 场没整理完，要补吗？"

```
影还在，就别让它白照。
```

代码：`lib/recovery.js`（只 stat 不读内容）+ 面板一键补出纪要。

## 三 · 魂的一侧

> 镜无心，故能照；人有心，故能守。

### 3.1 四层人格：魂有层

```
SOUL       它是什么      几乎不变
IDENTITY   怎么说话      很少变
USER       面对的是谁    慢慢长
STATE      此刻如何      每天变
```

**为什么必须分层？** 因为"会变"和"不变"不能放在同一个文件里。
底层被日常冲掉，人就长不出性格。

代码：`lib/persona.js`；会后自动追加 USER / STATE（只追加，不覆盖）。

### 3.2 记忆：会忘

给记忆设了**半衰期**：默认 3 天，强度减半。

```
factor = 0.5 ^ (dt / 3 天)
记得一切的工具，是把你当成静止的样本。
下次见面，它还会用三个月前的你，理解今天的你。
```

> 忘掉细节，留下形状。

这是整个项目最反直觉的设计：
**遗忘不是缺陷，是让"此刻的你"有机会被看见。**

### 3.3 信念：能生也能死

```
seed 0.3 → sprout 0.4 → sapling 0.6 → tree 0.85
                                     ↘ dead ≤ 0.02
强化 +0.2，反驳 −0.25
```

一条信念之所以可信，是因为它**还没被反驳掉**，
而不是因为它被登记成了"真理"。

**信念不自动种下**——它要你点头。
它可以替你记事、替你察觉气氛，但不能替你决定"什么值得相信"。

> 魂可以有心，不能有主人的心。

### 3.4 情绪：成地貌

六种情绪（喜、悲、怒、惧、静、惊）随时间衰减，
权重最高的会长成地貌：光原 / 湖 / 火山 / 雾 / 山谷 / 峰。

**它不进纪要。它决定分寸。**

```
火山在长 → 它闭嘴
光原铺开 → 它才敢提一句
```

判定是本地关键词，不调模型、不花钱、不怕断网——
因为"分寸"必须是**低延迟且永不掉线**的东西。

### 3.5 分寸：間

会中只在三种情况开口：

```
① 有人叫它
② 有值得追问的事
③ 被明确要求
```

其余时间，话收进账本。

> 間不是空，是**留出来的东西**。
> 话说满，人就没有地方思考了。

### 3.6 一期一会

同一场会只留**一条记录**：
同键 + 上一场未结束 + 45 分钟内 → 复用同一个目录、继续写同一本账。

```
那一场会，只发生一次。
所以不该因为它重启过，就变成好几场。
```

代码：`shouldReuseDir`；目录名按「软件 · 时间 · 主题」命名，一眼能认出。

### 3.7 初心

判定用的内部会话，每 200 轮或 45 分钟换一个新的。

```
越多的历史，越容易让判断被前面的话锚住。
换一个新会话，等于让它重新"什么都不知道"地听你说话。
```

### 3.8 守时与代劳

它能预约会议、到点自己进会、自己记、自己写库。

```
守时不是提醒你，是**替你在场**。
```

但它也清楚边界：电脑休眠、DSH 退出，就不会触发——
**这不是 bug，是它只能在"有人守着"的世界里工作。**

## 四 · 镜与魂之间

两半不是并列的，是**互相约束**的。

```
镜太强 → 什么都照，什么都不判断 = 一个昂贵的录音笔
魂太强 → 什么都判断，什么都不照 = 一个自信的骗子
```

所以项目里有一道很硬的线：

| 层 | 谁负责 | 规则 |
|---|---|---|
| **事实层** | 镜 | 必须确定：账本、时间戳、音频文件、回执 |
| **判断层** | 魂 | 允许模糊：建议、追问、要不要说话 |

**判断可以模糊，事实不能模糊。**
一旦反过来，就是灾难：用事实的确定性去伪装判断，或用判断的模糊去污染事实。

### 沉默是两边都要的

```
镜：不参与，所以沉默
魂：有分寸，所以也沉默
```

两条路走到同一个结论——**它大部分时间不说话**。

这不是没做完，是设计。

---

## 五 · 留白

一个镜子不画的地方，和画了的地方一样重要。

```
没有：让它自己决定要不要开会
没有：自动替你相信某个判断
没有：把每一句话都写进纪要
没有：在你不问的时候主动发言
```

> 器之所以有用，在其空。

---

## 六 · 一句话

> **镜照人，魂生念；照而不改，念而不夺。**

再短一点：

> **在场，而不侵入。**
